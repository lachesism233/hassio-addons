# Changelog 更新日志

All notable changes to the SRS Media Server app. / SRS Media Server 应用的版本变更记录。

## 6.0.191.2 - 2026-09-15

- Bilingual (English / Simplified Chinese) documentation and this changelog.
- English app name and description in the app store.
- 文档改为中英双语，并新增本更新日志。
- 应用商店名称与描述改为英文。

## 6.0.191.1 - 2026-09-15

- Remove ingress and open the built-in SRS web UI directly.
- 移除 ingress，改为直接打开 SRS 内置 Web UI。

## 6.0.191 - 2026-09-15

- Initial app: SRS 6.0 stable from the official ossrs/srs image, with the configuration generated from the app options.
- 首个版本：基于 ossrs/srs 官方镜像打包 SRS 6.0 稳定版，配置由应用选项生成。
