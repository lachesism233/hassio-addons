# hassio-addons

Home Assistant OS app (add-on) repository.

## Apps

| App | Description |
| --- | --- |
| [延时摄影 (HTTP Timelapse)](http-timelapse/) | Unattended scheduled JPEG capture from go2rtc/HTTP sources with retries, per-source schedules and a built-in gallery |

## Installation

1. In Home Assistant, go to **Settings → Apps → Install app**
2. Open the menu (⋮) → **Repositories**
3. Add `https://github.com/lachesism233/hassio-addons`
4. Install **延时摄影** and start it
