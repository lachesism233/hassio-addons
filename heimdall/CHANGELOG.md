# Changelog 更新日志

All notable changes to the Heimdall app. / Heimdall 应用的版本变更记录。

## 2.8.3.1 - 2026-09-15

- Bilingual (English / Simplified Chinese) documentation and this changelog.
- English app description in the app store.
- 文档改为中英双语，并新增本更新日志。
- 应用商店描述改为英文。

## 2.8.3 - 2026-09-14

- App version now follows the upstream Heimdall version.
- Internal lookup requests are allowed by default.
- 应用版本号改为跟随上游 Heimdall 版本。
- 默认允许向私有地址发起查找请求。

## 1.0.0 - 2026-09-14

- Initial app: Heimdall packaged from the LinuxServer image, with timezone and internal-request options.
- 首个版本：基于 LinuxServer 镜像打包 Heimdall，提供时区与内网请求选项。
